# AutoWeb Browser

**AutoWeb Browser** is a fully featured, high-performance Chromium-based web browser built specifically for Android, dashboard displays, and driving / vehicle integration. Designed with safety, touch optimization, offline caching, and voice control in mind.

## Creator
- **App Creator**: FourgeAI Labs ([GitHub Profile](https://github.com/fourgeailabs))
- **App Repository**: [AutoWebBrowser GitHub Repo](https://github.com/fourgeailabs/autowebbrowser)

## Key Features
- **Driving & In-Motion Optimization**: Unrestricted navigation for passenger and dashboard use with oversized touch targets and high-contrast dark mode.
- **Voice-Command Interface**: Intuitive speech recognition for hands-free searching, navigating, and bookmarking.
- **Full Video Playback**: Hardware-accelerated HTML5 video player support within WebView.
- **Session Persistence**: Automatically saves and restores the last open browser page.
- **Offline Support**: Cache articles, web pages, and media notes locally in Room DB for access without internet connectivity.
- **Customizable Bookmarks**: Instantly save, organize, and access frequently visited sites.
- **Google Assistant Integration**: Quick trigger intents for hands-free browsing.
